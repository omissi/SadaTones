# Privacy

Sada Tones is local-first in this build.

- Generated tones are saved locally in the app external files directory.
- Generated wallpapers are saved locally in the app external files directory and optionally to Pictures.
- Favorite state is stored in SharedPreferences.
- Request drafts are saved locally as text files.
- No analytics SDK is included.
- No ad SDK is included.
- No cloud upload is included.
- Contact permission is requested only when assigning a ringtone to a selected contact.
- Modify system settings permission is requested only when setting default ringtone, notification, or alarm sounds.

If a production release adds ads, billing, cloud backup, analytics, or remote AI generation, the privacy policy and Data Safety declaration must be updated before publishing.
